UNDER THE HOOD

Language in.
Tileable pixels out.

Blockloom is a local, procedural texture studio — not a cloud image model. It turns a short prompt into a deterministic material recipe, then grows the pixels from noise.

01

Read the prompt

A small vocabulary maps materials, finishes, colours, and accents. “Mossy cobblestone with cyan crystals” becomes a recipe.

02

Grow the surface

Periodic value noise, Worley cells, and hand-built patterns create stone, grain, grout, bark, and ore in 16, 32, or 64 px.

03

Quantize the palette

A compact colour ramp plus ordered dithering gives every pixel a job. Surface edges wrap, so side textures pass the four-way tile check.

04

Finish by hand

The pixel finisher adds pencil, eraser, eyedropper, fill, mirror, brush sizes, undo/redo, and independent side / top / bottom editing.

05

Keep everything

Every distinct texture you make is auto-archived in the local library — procedural, AI, and edited copies — with prompts, seeds, faces, palette, cuts, and version snapshots.

06

Ship it

Export a texture set with recipe metadata, copy a compressed share link, or open the pack builder to choose vanilla targets, stack works, pick a format, and write a drop-in resource pack.

The honest bit

The core is procedural and local. The optional AI layer sends a prompt to the provider shown in the AI dialog, then reduces the result to the same palette, seam, and export rules. The library stores everything in this browser’s IndexedDB; use Backup/Restore to move it between devices. AI is a concept source — the texture pipeline is still what makes it usable.

Procedural work stays local. AI is opt-in.
